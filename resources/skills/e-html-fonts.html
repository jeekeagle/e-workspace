e-html-fonts/选区字号编辑

给单文件 HTML 幻灯片装一套"选中文字后连续调整字号"的能力。改字号不重排版，不破坏原结构。

类型 · 运行时注入 形态 · 单文件 · 零依赖 依赖 · 无

01它是什么

e-html-fonts 是给单文件 HTML 幻灯片加装的"选区字号"运行时编辑层。

用法极简：跑一次安装器，把一段脚本注入到 </body> 之前，从此这一份 HTML 演示稿就支持"选文字 → 按快捷键 → 改字号"的能力。注入后仍然单文件、零依赖、可离线打开。

它只负责一件事：运行时选区字号。全篇默认字体、字体家族、版式设计不在它的边界内。

相同内容始终只有一个有效字号标记 span[data-html-fonts="1"]，不允许嵌套。

02为什么需要

HTML 演示稿改字号有三种典型场景，都很痛：

  • 临时强调某段——复制粘贴到 PPT 改字号再贴回来，破坏幻灯源代码、改了不想改的地方。
  • 现场调整——演讲时发现某段字号太小或太大，没法改，要靠"凑合讲过去"。
  • 反复试——想比较 24px / 28px / 32px 哪种合适，没有可逆工具。

通用富文本编辑器太重，浏览器原生命令只在当前会话生效。需要一种轻量、可注入、可持久化的中间态——这正是 e-html-fonts 提供的。

03设计原则

六条规矩，撑住"选区 + 单文件 + 可复用"三个承诺：

  1. 选区优先——只动选区字号，不动全篇默认字体、字体家族、版式。
  2. 单文件——注入后必须可离线打开，不引外链、不引 JS 库。
  3. 幂等——已有等价编辑器时不得重复注入；安装器要能反复跑。
  4. 持久化但有底线——按文本块写入 localStorage，恢复时先比原文，不让旧存档覆盖新版课件。
  5. 步进固定——每次 2px，范围 8–300px；多次按压可逆可回。
  6. 捕获阶段监听——快捷键命中字号操作时阻止默认缩放与翻页，避免副作用。

04布局结构

五步流程，单次安装：

① 读源 HTML　　　检测是否已含 adjustSelectionFontSize
　　↓
② 等价则跳过　　已有编辑器不重复注入
　　↓
③ 注入脚本　　　插入 </body> 前　单文件 · 零依赖
　　↓
④ 写 localStorage　按文本块持久化字号
　　↓
⑤ 验证步进　　　29 → 27 → 25 → 23

前两步是幂等保护，保证同一份课件可以反复注入不膨胀；后三步是运行时机制，由注入脚本在浏览器内完成。

05设计令牌

e-html-fonts 的"令牌"是行为参数，不是视觉令牌——一组决定运行时表现的硬约束：

参数 值 步进 2px / 次 字号范围 8 – 300 px 快捷键（增） Ctrl+= · Ctrl+Shift+> · Ctrl+滚轮上 快捷键（减） Ctrl+- · Ctrl+Shift+< · Ctrl+滚轮下 标记属性 span[data-html-fonts="1"] 持久化 localStorage（按文本块） 导出 Ctrl+S（仅当目标无自带导出器）

06内容块

模板内置 9 种 block，e-html-fonts 用得最多的是 code + pre：

# 安装（默认输出新文件，源文件不动）
node scripts/install-font-editor.mjs input.html --output output.html

# 仅在用户明确要求时覆盖原文件
node scripts/install-font-editor.mjs input.html --in-place
// 标记规范：相同内容只允许一个有效字号标记
// 旧标记 <font size="7"> 会被转换为：
<span data-html-fonts="1" style="font-size: 27px">...</span>

// 后续按键读取当前计算字号，而非原段落字号
const current = getComputedStyle(node).fontSize;

07怎么复用

五步开新页：

  1. 跑安装器——node scripts/install-font-editor.mjs input.html --output output.html，默认输出新文件，源文件不动。
  2. 检查幂等——再跑一次，输出文件不应多出第二份 adjustSelectionFontSize 或 data-html-fonts-installer。
  3. 打开浏览器验证——选中一段连续文字，按 Ctrl+- 三次，应看到 29 → 27 → 25 → 23px，Ctrl+= 反向恢复。
  4. 测折叠态——收起选区再继续按快捷键仍生效；Ctrl+滚轮 与别名产生相同步进。
  5. 测导出——Ctrl+S 应导出当前 HTML；若目标课件已有导出器，保留原行为不覆盖。

恢复字号时先比较文本块原文，旧存档不会覆盖新版课件内容。

08适用与不适用

适合：

  • 单文件 HTML 幻灯片——演讲、内训、产品发布，想临时调整字号。
  • 字号试错——在 24 / 28 / 32 px 之间反复比较，找到合适的。
  • 离线演示场景——注入后无外部依赖，U 盘拷过去即用。
  • 已有自定义脚本的小型课件——追加能力而非替换。

不适合：

  • 全篇默认字号调整——这是设计任务，不该在运行时改。
  • 字体家族更换、字重、字间距——超出"选区字号"边界。
  • 版式重排、网格调整——属于设计层，不归运行时管。
  • 需要协同的演示稿——localStorage 是本地的，跨设备不同步。
