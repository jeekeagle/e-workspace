A Skill Template

e-show-skill/skill 介绍页

固定风格、单文件 HTML、零依赖。把任意一个 skill 的文案塞进来，剩下的版式都不用动。

类型 · 静态模板 风格 · 白底 · 印刷感 依赖 · 零

01它是什么

e-show-skill 是一张固定版式的"skill 介绍卡片"。一份 HTML、一份 CSS、一段 14 行的 IntersectionObserver，没有别的。

用法简单：复制文件、改标题、改章节、改 meta，剩下的字体、配色、目录联动全自动。改一份样式，所有 skill 介绍页同步焕新。

设计意图是文档气质——可打印、可截图、可发链接，可存档。不是网页应用，是稿纸。换字不换格。

本页本身即一份示范：用 e-show-skill 模板写成的页面，介绍 e-show-skill 模板。

02为什么需要

skill 介绍页最容易掉进两个坑：

  • 每次都重画版式——每个 skill 单独排版，时间花在"怎样好看"上而不是"该讲什么"。
  • 界面花哨但读不进去——渐变、卡片堆叠、大色块，看着热闹，读到第三节就累了。

e-show-skill 走第三条路：克制到底，把精力省下来给内容。设计决策一旦定型不再博弈，所有后续介绍页的注意力都集中在"它解决什么问题、怎么用"。

03设计原则

四条规矩，支撑"固定风格"这个承诺：

  1. 克制——只用一种主色（墨青），其余靠灰度。不靠色块，不靠渐变。
  2. 可印——纯白底、衬线标题、深墨正文，打印出来不掉档。
  3. 可扫——窄单栏 + sticky 目录，扫一眼知道有多少节、读到哪了。
  4. 可改——所有 token 集中在 :root，换皮只动一处。

04布局结构

页面是一个 1000px 居中容器，两列网格：

.page　max-width: 1000px · margin: 0 auto
├── .side　目录列　200px　position: sticky; top: 64px
│　 ├── .brand　　　# 标识 + 状态点
│　 ├── .toc　　　　# 编号目录 + 滚动联动
│　 └── .meta-foot　# 元信息
└── main　主栏　680px　正文流
├── .topbar　# 章节条 + 版本
├── .lede　　# eyebrow / h1 / tagline / meta
└── section × N　# h2（编号）+ 正文块

滚动时目录粘在视口顶部 64px；窄屏 ≤ 900px 退化为单列，目录上移到主栏上方；打印时全部退化为普通文档流，page-break-inside: avoid 保证节不跨页。

05设计令牌

整套视觉的最小集合——改这里就能换皮：

--ink#14181c · 正文
--ink-soft#4a525a · 次级
--ink-mute#8a9099 · 辅助
--rule#e6e6e6 · 分隔
--accent#0f5e54 · 墨青

三件字体，刚好够用：

  • 衬线：Source Serif Pro / 思源宋体 / 宋体——大标题与引用
  • 无衬线：系统中文栈（苹方 / 雅黑）——正文
  • 等宽：SF Mono / Consolas——代码、meta、编号

06内容块

模板内置 9 种 block。只能用这些，不写新 CSS——一致性靠约束：

结构类

.lede　段首引导

.num　章节编号

.topbar　顶部条

数据类

.files　文件清单表

.split　两列对比

.palette　色卡

强调类

blockquote　引用

code / pre　代码

.demo　结构示意块

交互类

.toc　目录联动

section[id]　锚点

:hover / .active　状态

07怎么复用

四步开新页：

  1. 把 e-show-skill.html 复制成目标文件名。
  2. 改 <title> 与 .lede 区四个字段——eyebrow、名字、tagline、meta。
  3. 在侧栏 .toc 里同步改目录条目，给章节 section 加对应 id。
  4. 逐节替换 <section> 正文，只用模板内置 block。

改完别忘了把侧栏底标和页脚的版本号同步过去。

08适用与不适用

适合：

  • 长期维护一个 skill 集合，需要整齐划一的介绍页。
  • 文档气质优先——可打印、可截图、可存档。
  • 不想为每个 skill 重新设计版式。

不适合：

  • 交互复杂、需要图表、动画、可点 demo——稿纸不是仪表盘。
  • 想用品牌色、花字、彩色背景——它克制，不张扬。
  • 移动端为主——为桌面阅读和打印设计，窄屏是兜底不是主战场。
