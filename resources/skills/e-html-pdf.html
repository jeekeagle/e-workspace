e-html-pdf/HTML 转连续页 PDF

把任意 HTML 文档或定长 HTML 演示稿，导出为连续页 PDF。每张幻灯一页，隐藏态自动收齐。

类型 · 转换工具 引擎 · Edge headless 依赖 · Edge 浏览器

01它是什么

e-html-pdf 把自包含 HTML 文档和定长 HTML 演示稿，转成连续页 PDF。

底层是 Microsoft Edge 无头模式的 --print-to-pdf。上层做了三件普通截图工具不做的事：

  • 读 HTML——识别它怎么藏内容：visibility: hidden、.active / .visible、.reveal + opacity: 0。
  • 写 print CSS——强制覆盖隐藏态，让每一页都打印出来。
  • 验页数——生成后核对页数与可见性，缺页或留白回查原因。

目标产物是连续页 PDF——一张幻灯一页，没有交互控件，page-break-after 强制分页。

02为什么需要

HTML 演示稿的"显隐"靠 CSS class 控制，普通导出工具会撞两类墙：

  • 丢页——非活动幻灯 visibility: hidden，截图工具只看到当前页，整本演示被压成 1 张图。
  • 空白页——动画元素 opacity: 0 还没"动起来"，打印出来是白纸。

Edge headless --print-to-pdf 走的是真正的打印管线，配合 @media print 强制覆盖隐藏态，是目前 Windows 上最稳的可重复路径。再加一个 PowerShell 包装脚本，把路径处理、Edge 探测、文件等待、页数校验一次性收齐。

03设计原则

五条规矩，撑住"连续页 + 可见"这两个承诺：

  1. 打印可见性优先——@media print 里 visibility: visible !important，把隐藏态强制掀开。
  2. 一页一幻灯——break-after: page 强制分页，position: relative 切断 sticky 粘附。
  3. 动效归零——.reveal 的 opacity / transform / transition 在打印模式全部归零。
  4. 路径稳健——含空格或中文的路径必须加引号；每次新建 --user-data-dir，避免与已有 Edge 实例抢资源。
  5. 等待落盘——Edge 进程退出 ≠ 写入完成，必须 poll PDF 文件直到大小稳定。

04布局结构

五步流程，单文件收齐：

① 读 HTML　　　　识别隐藏态　visibility / .active / .visible / .reveal
　　↓
② 写 print CSS　　注入覆盖样式　@page + @media print
　　↓
③ 调 Edge　　　　无头打印　　--headless=new --print-to-pdf
　　↓
④ 等文件　　　　　poll 出现 + 大小稳定
　　↓
⑤ 验页数　　　　　对比声明页数 · 抽查可见性

前两步是对源 HTML 的预处理，要把它读懂、改对；后三步是确定性机械动作，由 PowerShell 包装脚本统一执行，避免每次重新发明轮子。

05设计令牌

e-html-pdf 是工具型 skill，没有视觉令牌。它的"令牌"是运行参数——一组影响导出行为的开关：

参数 作用 --headless=new 新无头模式（优先） --disable-gpu 关闭 GPU 加速，避免 headless 渲染抖动 --user-data-dir 每次新建，避免与已有 Edge 实例冲突 --no-pdf-header-footer去掉页眉页脚（页码、URL） --virtual-time-budget 给动画与字体 9s 预算（9000ms） --print-to-pdf 输出 PDF 路径

对应的 @page 与 @media print 关键属性——

06内容块

模板内置 9 种 block，e-html-pdf 用得最多的是 code + pre：

/* 演示稿的 print CSS 模板 */
@page { size: 1920px 1080px; margin: 0; }
@media print {
  .slide {
    visibility: visible !important;
    opacity: 1 !important;
    position: relative !important;
    display: block !important;
    break-after: page;
    page-break-after: always;
  }
  .slide .reveal {
    opacity: 1 !important;
    transform: none !important;
    transition: none !important;
  }
}
# Edge headless 打印（PowerShell）
& 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe' `
  --headless=new --disable-gpu `
  --user-data-dir="$env:TEMP\e-html-pdf-profile" `
  --no-pdf-header-footer `
  --virtual-time-budget=9000 `
  --print-to-pdf="$OutputPdf" `
  $HtmlUrl

07怎么复用

五步开新页：

  1. 读 HTML——打开源文件，定位 .slide、.active、.visible、.reveal、visibility: hidden 这些节点。
  2. 注 print CSS——把模板里的 @page + @media print 块加到 <style> 末尾，非幻灯稿按相同原则改写。
  3. 调脚本——运行 scripts/e-html-pdf.ps1 -HtmlPath <file> -PdfPath <file>；脚本会做路径归一、Edge 探测、headless 打印、文件等待、页数校验。
  4. 等文件——脚本默认 poll PDF 直到出现且非空；不要 Start-Process 后立刻读文件，Edge 退出前文件可能未释放。
  5. 验页数——声明 12 张幻灯但 PDF 只有 8 页？回查 .slide 选择器是否覆盖全部节点，或 .reveal 是否被 print CSS 正确归零。

如果 PDF 已在阅读器里打开，文件可能被锁。换个输出文件名再试，或先关掉阅读器。

08适用与不适用

适合：

  • 定长 HTML 演示稿——演讲、内训、产品发布，导出后存档或外发。
  • 自包含 HTML 文档——单文件报告、可视化长图、报告型手册。
  • 需要可重复的导出——CI 流水线里每周/每次发版自动出 PDF。
  • Windows + Edge 环境齐备——这是工具的硬约束。

不适合：

  • 动态加载内容——fetch、setTimeout 异步拉取的数据不会等。要预先内联到 HTML。
  • 需要登录态的页面——headless 模式不带 cookie / localStorage，登录墙挡路。
  • 巨幅 PDF（> 数百页）——Edge 单文件有内存与时间预算，超出会失败。
  • 像素级排版——Edge 打印对 CSS Grid 边界、Web Font 子像素对齐不如 Chromium PDF 精确。
